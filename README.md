# AUREON

A static luxury-experience website designed for GitHub Pages.

## Stack

- Semantic HTML5
- Modern CSS
- Vanilla JavaScript
- Google Fonts: Italiana + DM Sans
- No build step

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static HTTP server.

## GitHub Pages

Publish the repository from the `main` branch and the repository root (`/`).

## Before production

- Replace `concierge@example.com` with the final contact channel.
- Add final brand/legal copy.
- Replace conceptual experiences with the launch collection.
- Add analytics and privacy/cookie handling if required.
- Connect a custom domain when ready.
